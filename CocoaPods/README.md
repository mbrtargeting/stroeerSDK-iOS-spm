# CocoaPods Releases

This folder stores production CocoaPods release artifacts for the Ströer iOS SDK.

Each version contains:

- `yieldlove-ad-integration-<version>.zip`
- `YieldloveAdIntegration.podspec`
- `YieldloveAdIntegration-Confiant.podspec`

Example:

CocoaPods/
└── 10.7.0/
    ├── yieldlove-ad-integration-10.7.0.zip
    ├── YieldloveAdIntegration.podspec
    └── YieldloveAdIntegration-Confiant.podspec

These files are used only for CocoaPods distribution and are not part of the Swift Package products.
